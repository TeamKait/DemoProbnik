## Подтвержденная информация
1. Первый пробник - 15 октября, быть нужно всем
2. Пробников будет несколько. На каждом последующем ожидают результат лучше, чем на предыдущем
3. На настоящем демо экзамене не будет интернета, но будет возможность им отдельно воспользоваться на 15 минут
## Менее уверен
1. Ожидаемый результат на первом - готовая БД с данными и начало разработки UI: первая страница (авторизации) сделана или над ней начали работу
## Догадки
1. На пробнике будут такие же условия, как на экзамене: отсутствие интернета
## Слабо верю
1. За полностью проваленный пробник (буквально ничего не сделали) могут отчислить

# Оценка подходов
# ==🟣C\#==
## IDE
Visual studio (вероятно версия 2022 года)

## Библиотеки
- .NET

## UI
- Windows Forms
- WPF

>[!SUCCESS] Плюсы
>### C#
>- Строгий ООП типизированный язык
>- Нормальная асинхронность
>- Есть встроенный ORM (EF Core)
>- Большинство вещей решаются одним очевидным способом
>### IDE
>- Знакомая среда, мы с ним часто работали
>- Нормальный визуальный редактор UI
>- Хорошее определение ошибок
>- UI сразу рабочее

>[!FAILURE] Минусы
>### Windows Forms
>- кодовое представление UI плохо редактируется руками
>- Устаревшая философия: некоторые решения Microsoft по тому, как должна происходить разработка странные и неудобные
>- Редактирование свойств элементов неудобное и контринтуитивное
>### WPF
>- XAML в качестве языка разметки
>- Непонятная работа биндингов
>- Сложнее, чем Forms
>### ORM
>- Я не нашёл нормальной ORM с автомиграциями и с нормальной инициализацией (без билдеров билдеров, которые билдят билдеры в 10 оборотах `using`)
>### Общие проблемы
>- Мы изучали, как открыть новое окно, а не как заменить его содержимое. Потенциально это сложно


# ==🟣Python==
## IDE
- PyCharm
- VSCode

## Библиотеки
Мои личные рекомендации
#### БД:
- TortoiseORM: простая к использованию + есть автомиграции
#### UI:
- PySide6: +- норм, есть встроенный визуальный редактор, который устанавливается вместе с библиотекой. Чтобы открыть пропишите в терминале `pyside6-designer`

>[!SUCCESS] Плюсы
>### Python
>- Легкий язык
>- Быстрая разработка
>### IDE
>- PyCharm (особенно современный) много пишет за вас с помощью автокомплита. Иногда помогает, если что-то забыли
>### Tortoise ORM
>- Очень простая
>- Есть автомиграции: т.е. можно конвертировать модели из питона в таблицы в SQL
>- После миграции у вас сразу будет копия всех моделей в коде. Если вручную создавать таблицы, то такого не будет и связь будет более слабой (изменения в коде не изменяют саму БД)
>- Не нужно парсить результаты
>- Не нужно вручную писать запросы. Для этого есть функции: `User.all()` например
>### PySide6
>- есть встроенный в библиотеку визуальный редактор
>- визуальный редактор более удобный, чем в Visual Studio - можно более быстро делать layout'ы

>[!FAIL] Минусы
>### Python
>- Типизация необязательная, код держится на дисциплине
>- Непонятная асинхронность
>- Нужны отдельные библиотеки для асинхронности (asyncpg например)
>- Есть неочевидные вещи, которые нужно просто знать
>### IDE
>- VSCode практически не помогает писать код, плагины легко ломаются
>- Если не дадут скачать новую версию PyCharm, то помощи от него будет меньше
>### Tortoise ORM
>- Частые проблемы с закрытием подключения к БД
>### PySide6
>- Нужно компилировать .ui файлы в код
>- Приложение и ORM должны работать в отдельных потоках
